PART 1: THE CORE CONCEPTS (WHY THIS WORKED)
------------------------------------------------------------------------
To give you mobile options like Snapchat & Instagram (Gallery, Camera, or Files), we can't use a single generic file input. Instead, we use:

1. PHOTO GALLERY TRIGGER: 
   Adding <input type="file" accept="image/*"> instructs mobile OSs to pop up the Photo Library/Gallery directly.
2. TAKE PHOTO (CAMERA) TRIGGER:
   Adding <input type="file" accept="image/*" capture="environment"> instructs the phone to skip the gallery and directly open the Camera app.
3. BROWSE FILES TRIGGER:
   A standard <input type="file"> lets you open standard documents, recent files, snapchat downloads, or standard device download folders.

By intercepting the upload card click and opening a custom drawer, we let the user trigger the exact input they want!

export default function Upload() {
  const { isAuthenticated, user, loginWithRedirect, isLoading } = useAuth0();
  const [image, setImage] = useState(null);
  const [caption, setCaption] = useState("");
  const [uploading, setUploading] = useState(false);
  const [isDrawerOpen, setIsDrawerOpen] = useState(false);

  const galleryInputRef = useRef(null);
  const cameraInputRef = useRef(null);
  const fileInputRef = useRef(null);

  const handleFileChange = (e) => {
    const file = e.target.files[0];
    if (file) {
      setImage(file);
      setIsDrawerOpen(false);
    }
  };
-------------------
[WHY THIS CHANGE WAS MADE]
- `isDrawerOpen`: Controls the sliding bottom drawer display.
- `galleryInputRef`, `cameraInputRef`, `fileInputRef`: References to the separate hidden input elements so we can trigger them dynamically when the user selects an option in the drawer.
- `handleFileChange`: Listens to file selections, populates the image, and automatically dismisses the drawer for a fluid user experience.
