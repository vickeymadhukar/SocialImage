2. Image Upload & AI Auto-Tagging Flow

Canvas downscaling, streaming to Cloudinary with Google Vision Tagging, saving to MongoDB, and non-blocking Redis eviction.

100% 
sequenceDiagram
    autonumber
    actor User as User (Browser/Mobile)
    participant Client as React Client (Upload.jsx)
    participant Compressor as Canvas Compressor
    participant API as Express API (/posts/createpost)
    participant Cloudinary as Cloudinary + Google AI
    participant DB as MongoDB (Post Model)
    participant Redis as Redis Cache Engine

    User->>Client: Chooses Camera/Gallery & inputs caption
    Client->>Compressor: compressImage(file, preset='high')
    Note over Compressor: Aspect-ratio scale to 1600x1600
Converts to JPEG (q=0.82)
    Compressor-->>Client: Returns optimized file blob
    Client->>API: POST /posts/createpost (Multipart FormData)
    API->>Cloudinary: Multer streams image with categorization="google_tagging"
    Note over Cloudinary: Google Vision AI scans image
Generates tags & top category (confidence >= 0.7)
    Cloudinary-->>API: Returns secure_url, tags[], category
    API->>DB: Post.create({ image, caption, userId, tags, category })
    DB-->>API: Saved Post Record
    API->>Redis: clearPostsCache()
    Note over Redis: SCAN 0 MATCH 'posts:*'
DEL matching keys
    Redis-->>API: Feed caches cleared
    API-->>Client: HTTP 201 Created (Post payload)
    Client-->>User: Displays Success Toast & Redirects to Feed

3. Paginated Feed Retrieval & Redis Caching Flow

Cursor-based pagination pattern providing consistent $O(1)$ query speed and instant sub-millisecond cache hits.

100% 
sequenceDiagram
    autonumber
    actor User as User
    participant Client as React Client (Home.jsx)
    participant API as Express API (/posts/getallpost)
    participant Redis as Redis Cache
    participant DB as MongoDB (Post Model)

    User->>Client: Scrolls to bottom of masonry grid
    Note over Client: IntersectionObserver fires on sentinel
    Client->>API: GET /posts/getallpost?limit=10&cursor={nextCursorId}
    API->>Redis: GET posts:page:limit:10:cursor:{cursorId}
    
    alt Redis Cache Hit
        Redis-->>API: Stored JSON Feed Array
        API-->>Client: HTTP 200 OK (from Redis In-Memory)
    else Redis Cache Miss
        Redis-->>API: null
        API->>DB: Post.find({ _id: { $lt: cursorId } }).sort({ createdAt: -1, _id: -1 }).limit(11)
        DB-->>API: 11 Matching Documents
        Note over API: Slices 10 posts, identifies nextCursor & hasNextPage
        API->>Redis: SETEX posts:page:limit:10:cursor:{cursorId} 3600 (TTL 1 Hour)
        API-->>Client: HTTP 200 OK (posts, nextCursor, hasNextPage)
    end

    Client-->>User: Appends posts to Masonry Grid without layout shift

4. Full-Text Search & Category Filtering Flow

Instant search debounced at 400ms executed over MongoDB compound text index on caption and AI tags.

100% 
sequenceDiagram
    autonumber
    actor User as User
    participant Client as React Client (Search.jsx)
    participant Debounce as useDebounce (400ms)
    participant API as Express API (/posts/search)
    participant DB as MongoDB (Post Model)

    User->>Client: Types "sunset mountain" / selects "Travel" category
    Client->>Debounce: Registers keystrokes & category
    Note over Debounce: Waits 400ms idle to prevent API flooding
    Debounce-->>Client: Emits stabilized query parameters
    Client->>API: GET /posts/search?q=sunset+mountain&category=Travel
    API->>DB: Post.find({ $text: { $search: "sunset mountain" }, category: "Travel" })
    Note over DB: Evaluates textScore over { caption: "text", tags: "text" }
Sorts by score: { $meta: "textScore" }
    DB-->>API: Relevance-ranked Post results
    API-->>Client: HTTP 200 OK ({ count, data: posts })
    Client-->>User: Displays ranked search results in live grid

5. Auth0 Universal Login & User Profile Sync Flow

Decoupled OIDC identity provider sync with automatic pre-save age derivation from Date of Birth.

100% 
sequenceDiagram
    autonumber
    actor User as User
    participant Auth0 as Auth0 Universal Login
    participant Client as React Client (UserBoard / Setting)
    participant API as Express API (/users)
    participant DB as MongoDB (User Model)

    User->>Auth0: Logs in via Google / Social / Credentials
    Auth0-->>Client: Returns ID Token (sub, name, email, picture)
    Client->>API: POST /users/sync ({ userId: sub, name, email, profileImage })
    API->>DB: User.findOne({ userId })
    alt User Does Not Exist
        API->>DB: User.create({ userId, name, email, profileImage })
    end
    DB-->>API: User profile document
    API-->>Client: HTTP 200 OK (User Data)
    Client->>Client: Cache profile in localStorage
    
    opt User Updates Profile in Setting.jsx
        User->>Client: Edits bio, updates DOB or uploads avatar
        Client->>API: PATCH /users/profile ({ bio, dob, file })
        Note over DB: pre("save") hook recalculates user.age from dob
        DB-->>API: Updated User Record
        API-->>Client: HTTP 200 OK (Updated profile)
    end
